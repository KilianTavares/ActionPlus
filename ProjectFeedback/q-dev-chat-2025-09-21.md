Explain how to use the highlighted

---

The highlighted `@theme inline` directive is a Tailwind CSS feature that allows you to define custom CSS variables that Tailwind can use throughout your project.

Here's how it works:

**Purpose**: It creates a bridge between your CSS custom properties (CSS variables) and Tailwind's design system.

**Usage in your code**:
```css
@theme inline {
  --color-background: var(--background);
  --color-foreground: var(--foreground);
  --font-sans: var(--font-geist-sans);
  --font-mono: var(--font-geist-mono);
}
```

**What this enables**:
- Use `bg-background` class instead of manually writing `background: var(--background)`
- Use `text-foreground` class instead of `color: var(--foreground)`
- Use `font-sans` and `font-mono` classes with your custom fonts

**Example usage in components**:
```jsx
<div className="bg-background text-foreground font-sans">
  Content with custom theme colors and fonts
</div>
```

The `inline` keyword means these theme values are processed at build time and included directly in your CSS output, making them immediately available as Tailwind utility classes.
